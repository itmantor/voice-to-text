# تبدیل صدا به متن و ارزیابی تماس (Voice to Text)

یک وب‌اپ ساده که فایل صوتی را با API پلتفرم OpenAI به متن فارسی تبدیل می‌کند و تماس‌های مرکز تماس را با «استانداردهای پاسخگویی» مقایسه و امتیازدهی می‌کند.

- ورود با رمز عبور
- وارد کردن کلید API بعد از ورود (کلید فقط روی سرور ذخیره می‌شود، نه در گیت)
- پشتیبانی از mp3، m4a، wav، ogg، webm، mp4 و ...، تا ۵۰۰ مگابایت
- فایل‌های طولانی خودکار به تکه‌های ۱۰ دقیقه‌ای تقسیم می‌شوند (محدودیت ۲۵ مگابایتی OpenAI)
- مدل پیش‌فرض: `gpt-transcribe`؛ گزینهٔ `gpt-4o-transcribe-diarize` برای تفکیک گوینده (اپراتور / مشتری)
- بارگذاری چند فایل با هم
- بارگذاری فایل استانداردهای پاسخگویی (docx، PDF متنی، txt) در تنظیمات
- ارزیابی هر تماس: امتیاز کلی ۰ تا ۱۰۰، نتیجه، وضعیت هر معیار با شاهد از متن، موارد رعایت‌نشده، نقاط قوت و پیشنهادها
- گزارش تحلیلی هر تماس به‌صورت Word (راست‌چین، B Nazanin): متن کامل با تفکیک کارشناس و مشتری، مشکل اصلی مشتری، راه‌حل کارشناس، تحلیل احساسات مشتری و (در صورت انتخاب) ارزیابی با استانداردها

## نصب روی سرور (Ubuntu)

```bash
sudo git clone https://github.com/<USERNAME>/voice-to-text.git /opt/voice-to-text
cd /opt/voice-to-text
sudo APP_PASSWORD='رمز-دلخواه' bash install.sh
```

بعد از نصب، آدرس `http://IP-سرور:8095` را باز کنید، وارد شوید و از «تنظیمات کلید API» کلید را وارد کنید.

برای پورت دیگر: `sudo PORT=8096 bash install.sh`

## به‌روزرسانی

```bash
cd /opt/voice-to-text
sudo git pull
sudo bash install.sh
```

## دستورهای مفید

| کار | دستور |
| --- | --- |
| وضعیت سرویس | `sudo systemctl status voice-to-text` |
| دیدن لاگ‌ها | `sudo journalctl -u voice-to-text -n 50` |
| ری‌استارت | `sudo systemctl restart voice-to-text` |
| تغییر رمز | `sudo APP_PASSWORD='رمز-جدید' bash install.sh` |

## نکته‌ها

- رمز عبور در `/etc/voice-to-text.env` و کلید API، استانداردها و متن‌ها در `/var/lib/voice-to-text` نگهداری می‌شوند؛ هیچ‌کدام در گیت نیستند.
- OpenAI به سرورهای داخل ایران سرویس نمی‌دهد؛ سرور باید در منطقهٔ پشتیبانی‌شده باشد.
- در حالت تست (http با IP) ارتباط رمزنگاری نشده است. برای استفادهٔ واقعی دامنه و HTTPS اضافه کنید.
- مدل `gpt-4o-transcribe-diarize` طبق اعلام OpenAI در ۲۶ فوریهٔ ۲۰۲۷ از دسترس خارج می‌شود.
